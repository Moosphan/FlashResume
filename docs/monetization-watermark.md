# 免登录去水印变现方案

## 目标

在不强制用户登录的前提下，为 Flash Resume 增加轻量付费变现能力：

- 免费用户可正常编辑、预览和导出，但导出文件带水印。
- 用户可通过观看广告临时去水印。
- 用户可通过一次性付费获得更稳定的去水印权益。

## 设计原则

- 不登录也能完成核心流程。
- 不阻断简历编辑，只在导出权益上做差异。
- 免费路径可用，付费路径更省心。
- 权益说明必须清晰，避免诱导或误导。
- 支付和广告状态要可恢复，减少用户因刷新、关闭页面造成的损失。

## 权益分层

| 能力 | 免费版 | 看广告去水印 | 付费去水印 |
|---|---:|---:|---:|
| 在线编辑简历 | 支持 | 支持 | 支持 |
| 本地自动保存 | 支持 | 支持 | 支持 |
| 模板切换 | 支持 | 支持 | 支持 |
| 实时预览 | 支持 | 支持 | 支持 |
| 导出 JSON | 支持 | 支持 | 支持 |
| 导出 PDF / PNG / JPG | 带水印 | 指定次数内无水印 | 无水印 |
| 去水印有效期 | 无 | 短期 | 长期 |
| 使用门槛 | 无 | 看完整激励广告 | 一次性支付 |
| 推荐场景 | 体验、草稿 | 偶尔导出 | 正式投递、长期使用 |

## 免费版

免费用户不需要登录、支付或看广告即可使用完整编辑器。

限制只体现在导出文件：

- PDF / PNG / JPG 导出带水印。
- 水印文案建议：`Created with Flash Resume`。
- 水印位置建议放在页面底部或右下角，不能遮挡简历正文。
- JSON 导出不加水印，保证数据可迁移。

## 看广告去水印

### 权益

用户观看一次完整激励广告后，获得临时去水印权益。

建议规则：

- 每次广告解锁 `1` 次无水印导出。
- 可导出格式：PDF / PNG / JPG 三选一或一次导出动作。
- 权益有效期：`24` 小时。
- 未使用的广告权益最多累积 `3` 次。
- 广告加载失败时，不扣权益，不影响带水印导出。

### 适合用户

- 只需要偶尔导出一次简历。
- 不愿付费，但能接受广告换权益。
- 先试用无水印效果再决定是否付费。

### 体验流程

1. 用户点击导出。
2. 如果没有付费权益，弹出导出权益面板。
3. 用户选择“看广告去水印”。
4. 广告完整播放后发放一次无水印导出额度。
5. 用户继续导出，导出成功后扣减一次额度。

### 风险与限制

- 广告 SDK 通常依赖第三方脚本，可能被浏览器插件拦截。
- 海外和国内广告平台差异较大，需要按发布区域选择供应商。
- 纯前端发放权益容易被绕过，只适合轻量项目；如果收入规模变大，应引入后端校验。

## 付费去水印

### 权益

用户一次性付费后，获得长期去水印权益。

建议规则：

- 一次性购买，当前浏览器设备长期有效。
- 支持 PDF / PNG / JPG 无水印导出。
- 支持恢复购买凭证。
- 不限制导出次数。
- 后续新增模板仍可使用去水印权益。

### 适合用户

- 正式求职、频繁投递简历。
- 需要反复修改和多次导出。
- 不希望被广告打断。

### 体验流程

1. 用户点击导出。
2. 如果没有付费权益，弹出导出权益面板。
3. 用户选择“一次性去水印”。
4. 完成支付。
5. 本地保存权益凭证。
6. 后续导出自动无水印。

### 免登录凭证设计

免登录不等于无凭证。建议采用“本地凭证 + 可恢复码”的方式：

- 支付成功后生成一段恢复码。
- 本地保存权益状态到 `localStorage`。
- 用户可自行保存恢复码。
- 换浏览器或清缓存后，可输入恢复码恢复权益。

更稳的版本需要后端：

- 支付成功后由服务端生成 signed entitlement token。
- 前端保存 token。
- 导出前校验 token 是否有效。
- 恢复码只作为 token 查询入口，不暴露支付敏感信息。

## 推荐定价

初始版本建议低价一次性购买：

- 国内：`¥9.9` 或 `¥12.9`
- 海外：`$1.99` 或 `$2.99`

不建议一开始做订阅，原因：

- 简历工具使用频次偏阶段性。
- 免登录订阅恢复复杂度更高。
- 低价一次性购买更符合用户心理预期。

## 导出权益面板

触发时机：

- 用户点击 PDF / PNG / JPG 导出。
- 当前没有付费权益，也没有广告解锁次数。

面板内容：

- 免费导出：带水印。
- 看广告去水印：本次或一次导出无水印。
- 一次性去水印：永久无水印导出。

推荐文案：

```text
选择导出方式

免费导出
导出文件会带有 Flash Resume 水印。

看广告去水印
观看完整广告后，可获得 1 次无水印导出。

一次性去水印
不限次数导出无水印 PDF、PNG 和 JPG。
```

## 水印规则

水印只应出现在导出产物中，不出现在编辑器预览主界面。

建议样式：

- 文案：`Created with Flash Resume`
- 位置：每页底部居中或右下角
- 透明度：`0.35` 到 `0.5`
- 字号：不超过正文说明文字
- 不覆盖姓名、联系方式、经历正文等核心内容

## 数据结构建议

```ts
type ExportEntitlement = {
  paid: boolean;
  paidToken?: string;
  rewardedCredits: number;
  rewardedExpiresAt?: string;
  updatedAt: string;
};
```

本地存储 key 建议：

```text
resume_builder_export_entitlement
```

## MVP 实现范围

第一版建议只做这些：

- 导出前判断是否需要水印。
- 免费导出带水印。
- 本地模拟付费权益开关，打通 UI 和导出链路。
- 预留广告解锁入口和付费入口。
- 增加权益状态持久化。

第二版再接入真实商业能力：

- 激励广告 SDK。
- 支付平台。
- 恢复码或服务端 token。
- 订单和权益校验。

## 结论

推荐采用“三路径导出”：

- 免费：带水印，保证可用。
- 广告：临时去水印，适合偶尔使用。
- 付费：长期去水印，适合正式投递和高频导出。

该方案既保留免登录体验，也能把付费点放在用户真正有价值感的导出时刻。
