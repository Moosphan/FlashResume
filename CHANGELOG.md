# Changelog

All notable changes to this project are recorded here.

## 1.0.0

- Added a visible `v1.0` version badge in the header.
- Added a "More Settings" entry point with a slide-out settings panel.
- Added changelog browsing inside the settings panel by loading `CHANGELOG.md`.
- Improved README structure and updated preview images.
- Improved PDF export size by switching embedded PDF page images to JPEG and enabling PDF compression.
- Added export-only handling for the retail template to remove card shadows and avoid clipped edges in exported files.

## 0.9.0

- Added multi-template resume preview and industry gallery filtering.
- Added multi-format export support for PDF, PNG, JPG, and JSON.
- Added local persistence for resumes, theme mode, and editing state.
- Added tutorial panel and resume writing guidance content.

## 0.8.0

- Initialized the browser-based resume editor project.
- Added resume data model, editor forms, live preview, and theme color customization.
